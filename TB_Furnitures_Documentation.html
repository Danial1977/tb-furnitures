TB FURNITURES UK Section 01 : Executive Summary & Topology

System Architecture & Topology OVERVIEW

TB Furnitures is an enterprise-grade digital flagship designed for the British bespoke and handcrafted furniture sector. The platform integrates high-performance customer shopping experiences with an isolated, secure enterprise administration portal.

Key Architecture Highlight: The platform is engineered with a strict decoupled presentation layer. The customer storefront operates with dynamic 4-palette theme engines and luxury typography, while the administrative control panel runs inside an isolated, distraction-free environment with role-based governance and bulk CSV master data operations.

TB FURNITURES UK Section 02 : Relational Database Schema

Database Architecture & Entity Diagram SCHEMA

The database schema resides within the dedicated tb_furnitures PostgreSQL schema on Neon Serverless. The model guarantees referential integrity, financial precision using exact Decimal(10,2) data types, and immutable order snapshots for statutory tax compliance.

Figure 2.0 — Entity-Relationship Diagram (ERD) with Foreign Key Constraints

Core Data Dictionary

Table Name Primary Key Key Attributes & Constraints Business Logic & Notes
products id (UUID) sku (Unique), price Decimal(10,2), vatRate (20.00), widthCm, heightCm, depthCm Core furniture piece catalogue. Houses physical dimensions for 2-man room delivery calculations.
product_images id (UUID) productId (FK), url (Text), sortOrder (Int) Supports multi-angle studio galleries (front angle, room setting, and material close-ups).
categories id (UUID) slug (Unique), parentId (Self-referencing FK) Hierarchical category taxonomy for furniture rooms (Living Room, Bedroom, Dining Room, etc.).
orders id (UUID) orderNumber (e.g. TB-84910), userId (FK), totalAmount, status Order master with immutable shipping and billing snapshot and courier tracking numbers.
order_items id (UUID) orderId (FK), productId (FK SetNull), unitPrice, quantity Permanent snapshot of item name, SKU, price, and photo at the exact moment of sale.
users id (UUID) email (Unique), passwordHash, role (Enum) Manages roles: SUPER_ADMIN, ADMIN, ORDER_MANAGER, and CUSTOMER.
TB FURNITURES UK Section 03 : Backend & API Specifications

Backend Architecture & APIs API REF

All backend services are implemented as Next.js Route Handlers with type-safe request parsing, JWT authentication guards, and database transactions.

RESTful Endpoints Reference

Endpoint Route Method Auth Guard Function Description & Payload
/api/auth/[...nextauth] POST Public Credentials authentication provider. Validates email and bcrypt password, sets signed HTTP-only JWT.
/api/products GET Public Fetches products with query params: ?category=, ?search=, ?sort=price_asc|desc.
/api/products/[slug] GET Public Retrieves product specifications, multi-image gallery, active variants, and verified reviews.
/api/admin/products GET Admin Full product list with filters, stock levels, and pagination for table rendering.
/api/admin/products POST Admin Creates or updates furniture items. Also handles bulk CSV import and data transformation.
/api/admin/categories GET / POST / DELETE Admin CRUD for room categories with automatic slug generation and product relationship validation.
/api/admin/orders GET Admin Searchable orders table across customer names, postcodes, and order IDs with status filters.
/api/admin/orders/[id] GET / PUT / DELETE Admin Fetches order details, updates status (e.g. Dispatched + tracking code), or permanently deletes.
/api/checkout POST Customer Initiates Stripe payment intent or demo order placement with UK VAT and delivery calculation.

TB FURNITURES UK Section 04 : Frontend & Brand Experience

Frontend Engineering & Design System UI / UX

The customer storefront embodies modern British luxury, taking direct aesthetic inspiration from the geometric uppercase typography and tracking found in high-end design houses (e.g. Emporio Armani).

Emporio Armani Typography Implementation

Branding Typography Spec: Primary brand identifiers, top navigation elements, collection titles, and uppercase banners utilize high-impact geometric grotesque styling (Plus Jakarta Sans / Montserrat) set at font-extrabold with wide letter-spacing tracking-[0.2em] or tracking-[0.25em]. Body copy is rendered with clean modern sans-serif for reading comfort across high-DPI displays.

4-Palette Dynamic Theme Engine

The user interface features a live theme-switching swatch engine placed directly on the top announcement bar. Themes are applied instantly across the entire application tree without page reloads and persist seamlessly in the user's browser session.

British Heritage (Default)
Warm Cotswold honey, rich chestnut wood tones, and soft amber accents. Best for showcasing handcrafted solid European oak and heritage craftsmanship.
Midnight Noir (High Contrast)
Architectural monochrome styling. Automatically recalculates header typography to pure black or pure white depending on background elevation to ensure strict WCAG AA contrast.
Royal Nordic (British Navy)
Refined maritime navy blue combined with cool slate grey borders and crisp white cards. Ideal for contemporary living rooms and coastal collections.
Modern Sage (Botanical)
Earthy sage green tones with warm stone paper neutrals. Highlights sustainable timber sourcing, organic cotton bouclés, and eco-conscious finishes.

TB FURNITURES UK Section 05 : Admin Control Panel

Admin Control Panel Capabilities CMS

The Administrative Control Panel is accessible via /admin and provides full operational autonomy over master data, inventory levels, order workflows, and customer accounts.
